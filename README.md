## Overview

This project focuses on Exploratory Data Analysis (EDA) and Visualization of a Supermarket Sales dataset. The analysis was performed using Python in Google Colab.

The main purpose of this project is to understand sales performance, customer behaviour, product performance, payment preferences, and relationships between numerical variables.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains **1,000 transaction records and 17 original variables**. It includes information about:

- Branch
- City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Tax
- Total Sales
- Date and Time
- Payment Method
- COGS
- Gross Income
- Customer Rating

## Analysis Performed

The following EDA steps were performed:

1. Data loading and initial inspection
2. Dataset structure and data type analysis
3. Missing value and duplicate checking
4. Descriptive statistics
5. Date transformation
6. Sales category creation
7. Product-wise sales aggregation
8. Branch-wise sales aggregation
9. Payment method analysis
10. Customer type analysis
11. Data visualization
12. Sales distribution analysis
13. Quantity vs Total Sales analysis
14. Correlation analysis
15. Correlation heatmap
16. Key findings and business insights

## Visualizations

The project includes:

- Total Sales by Product Line
- Total Sales by Branch
- Transactions by Payment Method
- Distribution of Total Sales
- Quantity vs Total Sales
- Correlation Heatmap

## Key Insights

The analysis helps identify differences in product sales, branch performance, payment preferences, customer purchasing behaviour, and relationships among numerical variables.
